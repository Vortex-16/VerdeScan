# VerdeScan Frontend

This is the web dashboard for the VerdeScan Forest Monitoring System.

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Open Dashboard**
   Visit [http://localhost:3000](http://localhost:3000)

## Integration
This frontend connects to the FastAPI backend running at `http://localhost:8000`. Ensure the AI Model backend is running for full functionality.

For complete project documentation, see the [Root README](../README.md).
